# Configuration variables

All inputs are defined in [`infra/variables.tf`](../../infra/variables.tf) and set per
environment in `infra/environments/<env>/terraform.tfvars`. Nothing is account-specific
in source: the AWS account id is resolved at runtime from the caller identity, and the
region comes from `var.region`.

The few values that *are* account-specific (the deployed AgentCore runtime ARN, and — if
you enable SSO — the Federate `client_id` / `client_secret_arn`) live in **gitignored**
per-environment override files (`agent.auto.tfvars`, `federated.auto.tfvars`), never in the
committed `terraform.tfvars`. Terraform auto-loads any `*.auto.tfvars`, so they merge in on
a normal apply. See [environments](environments.md) and
[federated login](../operations/federated-login.md).

## Core

| Variable | Type | Default | Description |
|---|---|---|---|
| `project` | string | `tessera` | Prefix for every resource name (`<project>-<environment>-*`). |
| `environment` | string | — (required) | `dev` \| `staging` \| `prod`. |
| `region` | string | `us-east-1` | Deployment region. |

## Networking

| Variable | Type | Default | Description |
|---|---|---|---|
| `vpc_max_azs` | number | `2` | Availability Zones for the Lambda VPC. |
| `vpc_nat_gateways` | number | `1` | NAT gateways for private-subnet egress (use 2 in prod for HA). |

## Bedrock models

| Variable | Type | Description |
|---|---|---|
| `models` | object(map of ids) | Bedrock model / inference-profile ids per role: `builder`, `leaf`, `synthesizer`, `classify`, `external_eval`, `interactive`, `concierge`, `quorum`, `embeddings`. Override as models evolve. |

## Notifications

| Variable | Type | Default | Description |
|---|---|---|---|
| `admin_notify_emails` | list(string) | `[]` | Emails subscribed to the new-user signup-approval SNS topic. |
| `attention_email` | string | `""` | Optional email auto-subscribed to the human-in-the-loop attention topic. |

## Feature flags

| Variable | Type | Default | Description |
|---|---|---|---|
| `enable_quorum` | bool | `true` | Deploy the Quorum runtime and enable the quorum archetype. |
| `enable_websearch` | bool | `true` | Whether the web-search credential provider is expected (created out of band in the AgentCore token vault). |
| `allow_self_signup` | bool | `false` | When true, the login screen shows a "Create Account" tab and users can self-register (Cognito admin-create-only is disabled). Dev/demo only; keep false for staging/prod. See [admin user setup](../operations/admin-user-setup.md). |
| `demo_open_access` | bool | `false` | When true, adds AVP policies letting every authenticated user view + run ALL ecosystems, so self-registered colleagues see the owner-scoped demo solutions in the picker. Dev/demo only; keep false for staging/prod. Do not use `platform: true` on demo ecosystems for this — the solution picker hides platform ecosystems by design. |
| `signup_require_approval` | bool | `false` | Only relevant with `allow_self_signup = true`. true = new sign-ups are disabled until an admin enables them (+ SNS notice); false = usable immediately. |
| `federated_login` | object | `{ enabled = false }` | Optional OIDC SSO. Fields: `enabled`, `provider_name`, `issuer`, `client_id`, `client_secret_arn`, `default_group`, `create_users_group`. When disabled, the auth-federated module creates no resources. The committed `terraform.tfvars` keeps this `{ enabled = false }`; the real object (with the account-specific `client_id` / `client_secret_arn`) goes in the gitignored `environments/<env>/federated.auto.tfvars`. It's a single object — Terraform doesn't merge it across files, so set the whole object in the override. Procedure: [federated login](../operations/federated-login.md). |

## AgentCore

| Variable | Type | Default | Description |
|---|---|---|---|
| `agent_runtime_arn` | string | `""` | ARN of the AgentCore Runtime. Deployed by the `agentcore` CLI and fed back here (see [AgentCore runtime](../deployment/agentcore-runtime.md)). Empty on the first apply. |

## Lambda / logging / catalog

| Variable | Type | Default | Description |
|---|---|---|---|
| `lambda_runtime` | string | `python3.12` | Python runtime for all Lambdas. |
| `log_retention_days` | number | `30` | CloudWatch log-group retention. |
| `default_catalog_domain` | string | `cyber-security-risk` | Default catalog domain for the ingest / catalog APIs. |

## Secrets

There are **no secret variables**. The Cognito M2M client secret is generated by
Terraform and stored in Secrets Manager; the web-search API key lives in the AgentCore
Identity token vault (created out of band). Nothing sensitive is committed.
