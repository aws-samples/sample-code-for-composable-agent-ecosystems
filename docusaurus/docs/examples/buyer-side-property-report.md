# Buyer-Side Property Report

A guided walkthrough of a complete Tessera ecosystem, start to finish. The
**Buyer-Side Property Report** ecosystem takes a property a buyer is considering,
coordinates a set of agents to research it, and produces a single due-diligence
report the buyer can act on.

The four short clips below follow the full loop: **build** the ecosystem in the
visual Builder, **run** it, **watch** the live run, and **review** the finished
report. Each video is click-to-play.

## 1. Build the ecosystem

Compose the ecosystem in the visual Builder — adding agents, wiring their
dependencies into a DAG, and saving + deploying it. No code; the Builder compiles
the agent graph into a runnable workflow. For the full walkthrough, see
[Build an ecosystem](../guides/build-an-ecosystem.md).

## 4. Review the report

When the run finishes, the report agent assembles the final deliverable. Review
the structured report, its grounding indicators, and citations, and download the
produced artifacts. For how to read a run and iterate on it, see
[Run and review](../guides/run-and-review.md).
