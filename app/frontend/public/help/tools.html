Custom Tools

You can register additional tools backed by three target types:

Lambda ARN
Point to an AWS Lambda function. The agent invokes it directly via the Gateway.
OpenAPI Spec
Provide an OpenAPI 3.0 spec (JSON or YAML). The Gateway auto-generates tool operations from the spec.
MCP Server
Connect to a remote Model Context Protocol server. The Gateway proxies tool calls to the MCP endpoint.

Registering a Tool

  1. Choose + Add Tool in the top-right
  2. Enter a name (must match what agents reference in their tool list)
  3. Enter a description
  4. Select the target type (Lambda, OpenAPI, or MCP Server)
  5. Provide the target configuration based on your target type: Lambda ARN, OpenAPI specification, or MCP Server URL
  6. (Optional) Configure credentials by entering the API key and header name
  7. To verify connectivity, choose Test
  8. To register the tool, choose Save
The tool name must exactly match what's declared in ecosystem YAML agent tool lists. Use snake_case.

Credentials

If your tool requires authentication, configure an API key credential:

  • Credential name — identifier for the credential provider
  • API key — the secret key (stored securely in AgentCore Identity Token Vault, never in code)
  • Header name — which HTTP header carries the key (default: X-API-Key)
API keys are stored in AgentCore Identity and never exposed in the UI after saving. To rotate, edit the tool and provide a new key.

Testing Tools

Two ways to test:

  • During registration — the Test button in the add/edit modal verifies the endpoint is reachable and credentials work
  • From the catalog table — choose Test on any registered tool to check its current status and credential configuration

Unregistered Tools

The bottom section shows tools that are declared in ecosystem YAMLs but not yet registered. These appear with:

  • Expected purpose — inferred from the ecosystem context
  • Fallback behavior — agents improvise using system tools until the custom tool is registered
  • Used by — which ecosystems/agents reference this tool
  • Register button — opens the registration form pre-filled with the tool name
Ecosystems work without custom tools registered — agents improvise. But registering the actual tool gives them real data instead of approximations.

Editing & Deleting

From the registered tools table:

  • Edit — update description or credentials (target type cannot be changed after creation)
  • Delete — removes the tool registration. Agents referencing it will fall back to improvisation.
