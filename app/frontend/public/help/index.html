What is Tessera?

Tessera is a composable agentic security platform. You define ecosystems — multi-agent workflows described in YAML — and Tessera orchestrates them: running agents in parallel or sequence, verifying their outputs for accuracy, and presenting results in real time.

No code required. Configuration over code.

Key Concepts

⬡ Ecosystem
A multi-agent workflow. Contains agents, their dependencies, tools, memory configuration, and quality settings. Defined in YAML, compiled to Step Functions.
🤖 Agent
An AI agent with a system prompt, tools, and dependencies. Agents run on Amazon Bedrock via AgentCore Runtime and produce structured findings.
🔧 Tool
A capability an agent can use: web search, code interpreter, memory, HTTP requests, or custom tools you register (Lambda, OpenAPI, MCP).
🛡️ Quality Layer
Automatic verification: challenger agents stress-test findings, internal grounding checks claims against evidence, external grounding verifies via web search.
📊 Run
A single execution of an ecosystem. You provide a mission and inputs, then watch agents work in real time. Results are persisted for review.
🧠 Memory
Shared namespaces that agents read from and write to. Supports semantic, episodic, and summarization strategies.

Quick Start

  1. Select an ecosystem from the Ecosystems view
  2. Choose ▶ Run in the action bar
  3. Enter a mission describing what you want the agents to accomplish
  4. Fill in any required text input fields
  5. Upload any required files
  6. Choose ▶ Launch
  7. Watch agents run in real time
  8. To focus on a specific agent's output, choose the agent in the DAG or card strip
  9. When complete, review the final report
  10. Review the outcome panel
