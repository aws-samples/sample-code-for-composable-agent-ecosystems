Frequently Asked Questions

Common questions and troubleshooting.

General

What models does Tessera use?

Agents run on Amazon Bedrock, primarily using Claude Sonnet 4. The model is configured at the system level — you don't need to select it per agent.

Do I need to write code to create an ecosystem?

No. Ecosystems are defined in YAML via the Builder UI. You can use AI assistance to generate the entire configuration from a natural language description.

Can I run multiple ecosystems simultaneously?

The UI tracks one active run at a time. However, multiple runs can operate in the backend — you'll see the most recently launched one in the Live Run view.

Running

My run seems stuck — nothing is happening

Check the activity strip. If it shows "Verifying findings" or "External grounding", quality checks are running between agent layers. These can take 10–30 seconds per agent. If the connection indicator shows "polling" or "offline", your WebSocket may have dropped — the run continues in the backend regardless.

How do I describe what a run should do?

The run dialog is conversational by default: describe your goal and the planner asks one focused question at a time until it has a complete brief for that ecosystem (you can watch the briefing checklist fill in on the right). It won't let you launch — or invent details you didn't give — until the brief is complete. Prefer a one-shot? Choose Type it myself for a plain mission box.

Can I attach files to a run?

Yes — every run dialog has an optional "Attach files" area, for any ecosystem. Attachments are classified and considered in the mission chat, then passed to the agents. Some ecosystems also declare specific (sometimes required) file-input fields. See Files.

A run failed — can I retry? And what about a run that "succeeded" but produced nothing?

Two options from 📜 History: Redrive resumes a failed run from the failure point (native, completed agents aren't re-run). Resume from here is more general — click any node in the run's DAG and resume from there, reusing all completed upstream steps. It works for failed and succeeded runs alike, so you can re-run just the final step of a "succeeded but empty" run without redoing the whole pipeline.

What does the cost figure in telemetry mean?

It's an internal estimate — model list prices × the tokens each agent used — for comparing runs and agents. It is not an authoritative bill; consult the AWS console for actual charges.

I refreshed the page during a run — is it lost?

No. Tessera persists active run state to your browser's local storage. On reload, it automatically resumes tracking via AWS Step Functions polling.

What does "polling" mean in the connection indicator?

The WebSocket connection dropped (common after ~10 minutes of idle). Tessera falls back to polling Step Functions every 5 seconds. The run continues normally — you get slightly delayed updates.

How long do runs typically take?

Depends on the ecosystem. Simple 3-agent ecosystems: 30–60 seconds. Complex ecosystems with 8+ agents, grounding checks, and challenger: 3–8 minutes. The activity strip shows progress throughout.

Builder

Can I edit a system-managed ecosystem?

No. System-managed ecosystems (marked 🔒) are maintained by the Tessera team. You can clone the concept by creating a new ecosystem with similar agents.

What happens when I save an ecosystem?

The YAML is saved to the backend and compiled into a Step Functions state machine. The ecosystem becomes immediately available for running. No separate deploy step needed.

Can agents run in parallel?

Yes. Agents with no depends_on (or whose dependencies are all satisfied) run in parallel automatically. The DAG visualization shows which agents can run simultaneously.

What's the difference between orchestrated and choreography?

Orchestrated uses a static DAG — you define dependencies explicitly. Choreography is event-driven — agents trigger based on events other agents emit. Most ecosystems use orchestrated.

Tools

What happens if I reference a tool that isn't registered?

The agent still runs. It improvises using system tools (web_search, http_request, etc.) to approximate the missing tool's functionality. Registering the actual tool gives agents real data.

How do I rotate an API key for a tool?

Go to Tool Catalog → choose Edit on the tool → enter the new API key → Save. The old key is replaced in AgentCore Identity Token Vault.

Can multiple tools share the same credential?

Each tool registration has its own credential configuration. If multiple tools use the same API service, you'll configure the key separately for each.

Quality

Can I disable grounding checks for faster runs?

Yes. In the Builder, uncheck "Grounding checks" under Quality Features. This skips internal and external verification. Not recommended for production use.

What does "contradicted" mean in external grounding?

The agent made a claim that web search results actively contradict. This is stronger than "unverified" (no evidence found) — it means evidence exists that says the opposite.

Why did my agent fail with "missing STRUCTURED FINDINGS"?

Every agent must produce output containing ## STRUCTURED FINDINGS and ## OPEN QUESTIONS sections. This is a hard requirement — no fallback. The agent's prompt may need adjustment so that it produces this format.

Troubleshooting

The ecosystem list is empty

Check that the backend API is reachable. The status indicator in the sidebar should show "Amazon Bedrock connected". If not, the API URL may be misconfigured or the backend may be down.

AI suggestion is stuck on "Thinking..."

The suggest feature requires an active WebSocket connection to receive the async result. If the WebSocket indicator shows disconnected, refresh the page and try again.

File upload shows no progress

Files upload directly to S3 via presigned URL. Large files may take time. After upload, classification takes a few seconds. Refresh the file list if the status doesn't update.
